# Two-minute demo script

**0:00–0:08 — Set context.**

“Aster is an independent, evidence-first Q&A prototype for general Vedic
astrology concepts. It is not affiliated with Melooha and it does not make
personal chart predictions.”

**0:08–0:28 — Explore the sky and Panchang.**

Open the constellation sky, drag the interactive sphere, select a constellation,
and show its named stars and SIMBAD source. Clarify that sidereal Rashis are
30-degree sectors rather than IAU constellations. Open Panchang, change the
city/date, and explain local sunrise and the approximate calculation convention.

**0:28–0:43 — Explore Astropedia.**

Open Rashi Explorer, show all 12 signs, and open one detail page. Drag the
NASA-photo solar-system gallery and expand its image credits, then use the
“Ask about” action to carry a sign-specific educational question into the
composer. Clarify that the animated, not-to-scale gallery is not a personal
chart calculation. Open Chart Learning, select a house or Graha, and drag the
three-dimensional model. Then open My Birth Chart, enter a test date, time,
timezone offset, and coordinates, and inspect the locally calculated
placements and timing-period note. Explain its approximate conventions.

**0:43–1:15 — Ask Vaani and explain trust.**

Show the available question balance and submit a supported concept question.
Point out genuine server-to-client answer delivery. Open the evidence panel and
show the exact retrieved fact text and source label.
Explain that Gemini/Groq may select only retrieved fact IDs; the server checks
those IDs and composes the displayed answer from stored text. If no API key is
configured, curated mode remains clearly labelled.

Switch to Hindi and ask a supported educational question; show that the
reviewed answer and evidence are in Hindi and that a personal prediction stays
out of scope.

**1:15–1:30 — Save and revisit.**

Ask an unrelated or personal-reading question. Show the explicit insufficient-
evidence state rather than a fabricated prediction. Save a supported answer,
then show it in Cosmic Journey. Add a private reflection and reload the page to
demonstrate database persistence.

**1:30–1:45 — Try the private scan and voice.**

Open On-device Scan Lab, request camera permission, and show a local face or
hand landmark overlay. State that it checks framing only; it does not read
palm lines or infer a person's future. Then demonstrate browser voice input or
answer playback when supported.

**1:45–1:55 — Credits and design system.**

Use the demo top-up to show that it grants demo credits only and does not
process payments; mention server-side balance enforcement and idempotency.
Open the living style guide to show shared tokens and components.

**1:55–2:00 — Engineering close.**

Show the evaluation report and CI checks. State the limitations honestly: a
small curated corpus, approximate chart conventions, no predictive image
readings or real astronomical timeline, no deployment, and live provider calls
not verified without configured API keys.
